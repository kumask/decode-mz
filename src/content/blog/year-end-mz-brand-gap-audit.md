十一月底開始，大多數企業主管的桌上都會出現同一件事：明年的品牌策略規劃書。

你可能已經知道要「加強年輕族群的觸及」、「優化社群內容」、「讓品牌更有活力」。但在你把這些方向寫進PPT之前，我想問你一個問題：

**你有沒有量測過，你的品牌和MZ世代之間，現在距離是幾公里？**

不是感覺。不是你的行銷團隊給你的報告。是你自己真正知道的那個答案。

大多數主管對這個問題的回答，分成兩種錯誤：

第一種是過度樂觀。「我們有做Instagram，有在下廣告，有找KOL合作，應該不差。」這類主管通常用「有在做」來代替「做得有沒有用」。

第二種是逃避問題。「我們的目標客群主要是35歲以上，MZ世代不是我們的核心，所以沒關係。」這類主管通常沒有意識到，即使你不賣東西給MZ，他們也在替你的品牌打分數——而且他們的評分會影響整個市場對你的認知。

年底是做這件事最好的時機。預算還沒鎖定，策略還在形成，你還來得及用真實的資料做出有根據的決策。

以下是我給主管的五步驟品牌差距分析法。

---

## 步驟一：聽——收集MZ世代對你品牌的「原聲」

不要透過你的行銷部門過濾。直接去找原始資料。

打開你品牌的Instagram、Dcard、PTT，以及最近一年的Google評論。把提到你品牌的留言全部截圖存下來，特別是有溫度的那種——不管是讚美、抱怨、還是嘲諷。

**你要找的不是「數量多少」，而是「用什麼詞彙描述你」。**

如果年輕人在留言裡用「老牌」、「傳統」、「老爸在用的」這類字眼，那不是褒，是你品牌年齡的診斷書。如果沒有任何留言，那個沉默本身就是答案。

這一步的目標：整理出五個MZ世代用來描述你品牌的高頻詞彙。這就是你的品牌形象現況。

---

## 步驟二：看——掃描你的品牌在MZ生活場景中的存在感

拿出你的手機，用你不常用的帳號（或請一個25歲的同事做這件事），在以下幾個地方搜尋你的品牌名稱：

- Threads
- Instagram Reels 和限時動態
- Dcard 討論區
- YouTube 搜尋結果

記錄以下幾件事：
1. 搜尋結果的第一頁，哪些是你自己產出的內容，哪些是用戶自發產出的？
2. 用戶自發的內容，整體情緒是正面、中性還是負面？
3. 你的競品在同樣的平台上，自發用戶內容的量是你的幾倍？

**很多主管在這一步才第一次「看見」自己的品牌在年輕人的眼中長什麼樣子。**

有時候這個落差是讓人沮喪的。但這正是做這件事的意義——在年初預算討論之前，先讓自己清醒。

---

## 步驟三：問——訪談五個MZ世代

這一步很多主管會跳過，因為「沒有時間」或「已經有市調數據了」。

我的建議：跳過的話，前兩步的資料只有一半的價值。

你不需要花三個月做正式焦點團體。你需要的是五場每場20分鐘的非正式對話，對象可以是你公司的年輕員工、你產品的年輕消費者，或者你認識的朋友的孩子。

問以下三個問題就夠了：

1. **「你有沒有聽說過我們這個品牌？你第一個想到的是什麼？」**
   聽形容詞。聽語氣。聽他們猶豫的地方。

2. **「如果我們這個品牌是一個人，你覺得他幾歲？在做什麼工作？」**
   這個問題能逼出他們對品牌人格的直覺感受，比任何量表都準確。

3. **「你上一次主動推薦或分享我們品牌相關的東西是什麼時候？為什麼那次會分享？」**
   如果答案是「從來沒有」，追問為什麼。那個理由才是關鍵。

五個訪談，你就會開始看到重複出現的模式。那個模式就是你品牌在MZ世代心中的真實定位。

---

## 步驟四：比——和一個MZ原生競品做並排比較

找一個同類別中，你認為「很懂年輕人」的競品或新興品牌——不一定要是直接競爭者，可以是你仰慕的品牌。

做一個並排比較表，從以下維度各給1-5分：

| 維度 | 你的品牌 | 對比品牌 |
|------|---------|---------|
| 社群語言的親和感 | | |
| 用戶自發內容的量 | | |
| 品牌議題的話題參與度 | | |
| 視覺風格的當代感 | | |
| 與MZ生活情境的連結度 | | |

**重點不是你的總分，而是哪個維度的落差最大。**

落差最大的那個維度，就是你明年最值得集中資源改善的地方。品牌年輕化最容易犯的錯，是試圖同時改所有事情，結果每個方向都只動了一點點，沒有任何一個改到MZ世代真正感知得到的程度。

---

## 步驟五：判——做出一份清晰的品牌差距評估

把前四步的資料整合成一頁紙。格式很簡單：

**現況描述（一句話）：**
MZ世代目前用來描述我們品牌的核心印象是＿＿＿。

**差距評分（1-10）：**
我們品牌和MZ世代對「理想品牌」的期待之間，現在的距離是＿＿分（1=非常遠，10=非常近）。

**最大弱點（一個）：**
如果只能改一件事，應該優先改＿＿＿。

**明年品牌目標（一句話）：**
一年後，我希望MZ世代用來描述我們品牌的核心印象改變為＿＿＿。

**這一頁紙，就是你明年品牌策略的起點，不是任何顧問公司做的長篇報告。**

它的價值不在於複雜度，而在於它來自真實資料，不是你在會議室裡的直覺和假設。

---

## 為什麼年底做這件事，比年初做更有效

年初做品牌規劃，大多數人是在填表格——把去年的策略改個數字繼續用。

年底做差距盤點，你是帶著一整年的真實結果，重新校準你的出發點。

而且，年底是MZ世代對品牌最有感的時刻之一。聖誕節、跨年、各種盤點型內容大量出現，他們對品牌的討論和分享都在升溫。這個時間點收集到的資料，比任何其他月份都更有代表性。

---

## 給主管的最後一個提醒

做完這五步，你不一定會喜歡看到的結果。

品牌和MZ世代的距離，往往比主管預期的更大。這不是誰的失誤，是時代移動的速度本來就比品牌改變的速度快。

但差距有多大，你才能決定要用多快的速度、多少資源去縮短它。

如果你做完這個盤點，發現結果讓你不知道從哪裡開始，或者你看到差距但不確定如何把它轉換成具體的品牌行動，那是一個值得找品牌教練談一次的時機。
